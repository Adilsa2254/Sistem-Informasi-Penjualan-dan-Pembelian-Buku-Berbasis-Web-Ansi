# Sistem-Informasi-Penjualan-dan-Pembelian-Buku-Berbasis-Web-Ansi

Sistem informasi penjualan dan pembelian buku berbasis web dengan satu basis
data, yang memperbarui stok secara otomatis dan memudahkan pemantauan
inventaris.

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.



## DataBase

1. Pelanggan:
    * ID Pelanggan
    * Nama
    * Gender
    * Email
    * No_Hp

2. Pembelian:
    * Id_pembelian
